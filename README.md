# Clicker Game 🎮

A simple and addictive idle/clicker game built with **HTML5**, **CSS3**, and **JavaScript**. Click to earn points, sell them for money, and buy powerful upgrades to progress!

## Features ✨

* **Main Clicker:** Click the button to accumulate clicks up to a specific limit.
* **Sell System:** Convert your accumulated clicks into money.
* **Upgrade Shop:** 
  * **Limit Boosts:** Increase your maximum click capacity.
  * **Click Boost:** Increase your click power (get more clicks per click).
  * **Autoclicker:** Automatically generate clicks over time.
* **Bilingual:** Available in English and French.

## Technologies Used 🛠️

* **HTML5** (Structure)
* **CSS3** (Styling with Grid & Flexbox)
* **JavaScript** (Game logic, DOM manipulation, timers)
